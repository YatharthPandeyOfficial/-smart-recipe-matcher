# 🍽️ Smart Recipe Matcher

A Streamlit web app that helps users find meal recipes based on ingredients they already have. It uses **TheMealDB API** to search recipes and shows matched ingredients, instructions, and full recipe links.

---

## 📌 Features

- 🌿 Enter your available ingredients
- 🔍 Find matching recipes from TheMealDB
- 🧂 See which ingredients matched
- 📋 Step-by-step cooking instructions
- 🌐 Link to full recipe on TheMealDB

---
## 🚀 How to Run the App

# 1. Clone this repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

# 2. Install required Python packages
pip install -r requirements.txt

# 3. Run the Streamlit app
streamlit run app.py

## 🛠️ Tech Stack

- **Frontend/UI**: Streamlit
- **Backend**: Python
- **APIs**: [TheMealDB API](https://www.themealdb.com/api.php)
- **Libraries**: 
  - `requests` – for making API calls
  - `streamlit` – for building the web app UI
